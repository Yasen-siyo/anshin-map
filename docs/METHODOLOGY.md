# 점수 계산 방법

모든 값은 `scripts/config.py` 에서 바꿀 수 있습니다.

## 1. 격자

- 범위: 위도 34.89~36.11, 경도 138.90~140.88 (도쿄 섬 지역 제외, 가나가와·지바 전체)
- 격자: 100m × 100m, Web Mercator 정렬 (구글맵·OSM 타일과 같은 좌표계라 이미지를 그대로 겹칠 수 있음)

## 2. 시설 점수

OpenStreetMap 에서 아래 시설을 모아, 각 시설의 가중치를 표준편차 150m 가우시안으로 퍼뜨려 합산합니다.

| 종류 | OSM 태그 | 가중치 |
|---|---|---|
| 스트립클럽 | amenity=stripclub | 4.0 |
| 성매매 업소 | amenity=brothel | 4.0 |
| 나이트클럽 | amenity=nightclub | 3.0 |
| 파칭코·슬롯 | leisure=adult_gaming_centre, gambling=pachinko, 이름에 パチンコ 등 | 2.5 |
| 도박(마작 등) | amenity=gambling/casino | 2.0 |
| 성인용품점 | shop=erotic/adult | 2.0 |
| 러브호텔 | amenity=love_hotel, tourism=hotel + hotel=love | 2.0 |
| 바 | amenity=bar (amenity=pub 은 이름이 바·스낵·라운지 계열일 때만) | 1.0 |
| 물담배 | amenity=hookah_lounge | 0.5 |

제외:
- 이자카야: 일본 OSM 에서 amenity=pub 은 대부분 이자카야 체인이라 기본 제외. 이름에 居酒屋·焼鳥·魚民 등이 있으면 bar 로 태깅돼 있어도 제외.
- 편의점, 파칭코 경품 교환소(換金所), 복권 판매점.

정규화: 로그 척도로, 가중 합 1.5 이하(바 한두 곳)는 위험 0, 40 이상(가부키초 수준)은 위험 1.

## 3. 범죄 점수

세 현 모두 町丁(동네) 단위로 공개하는 거리 범죄만 씁니다. 현마다 공개 범위가 달라,
한 현에만 있는 범죄 종류를 넣으면 현 경계에서 점수가 끊기기 때문입니다.

| 범죄 | 가중치 | 이유 |
|---|---|---|
| ひったくり 날치기 (지바는 路上強盗 노상강도) | 4.0 | 길에서 사람을 노리는 범죄 |
| 車上ねらい 차량털이 | 1.0 | 기준 |
| 自動車盗 자동차 도난 | 0.8 | |
| オートバイ盗 오토바이 도난 | 0.5 | |
| 自販機ねらい 자판기 털이 | 0.5 | |
| 自転車盗 자전거 도난 | 0.1 | 건수가 압도적으로 많고 역 앞 인파와 겹쳐 여행자 체감과 거리가 멂 |

- 기간: 2025년 1~12월
- 町丁별 (건수 × 가중치) 합 ÷ 면적(km²) → 격자에 칠한 뒤 약 150m 흐림
- 정규화: 로그 척도로, 8 이하는 위험 0, 60 이상은 위험 1
- 폭행·상해·강도 같은 강력범죄는 도쿄만 町丁 단위로 공개해서 넣지 않았습니다.

## 4. 합산

```
위험 = 0.7 × max(시설, 범죄) + 0.3 × (0.55 × 시설 + 0.45 × 범죄)
안심도 = round(100 × (1 − 위험))
```

어느 한쪽만 심해도 위험으로 잡히도록 큰 쪽을 70% 반영합니다.

## 한계

- OSM 시설 정보는 자원봉사자가 입력한 것이라 지역마다 빠진 곳이 있을 수 있습니다.
- 범죄 통계는 신고된 건수이고, 낮 인구가 많은 업무지구는 면적당 건수가 높게 나오는 경향이 있습니다.
- 강력범죄, 조명, 인파, 호텔 자체의 보안은 반영되지 않습니다.
